# Augment Selection Icon Prompts

## 공통 지시

48×48 표시에서도 즉시 읽히는 증강 선택 UI 아이콘. 공식 게임 이미지의 dark graphite/navy 기업 도시 기계 재질, cyan 에너지, oxidized orange/coral 위험 강조만 분위기 기준으로 사용한다. 부드러운 안티앨리어싱, 굵은 실루엣, 절제된 음영과 rim light를 사용하고 주 대상 하나와 기능 단서 하나만 중앙에 둔다. 픽셀 아트 제약은 적용하지 않는다. 프레임·배지·장면·인물 초상·문자·숫자·워터마크·미세 장식·색상만의 구분은 금지한다.

## 증강별 핵심 형태

1. `fast-launch`: 발사기에서 갈고리가 바깥으로 튀어나가며 세 줄의 속도 궤적이 생긴다.
2. `long-rope`: 화면 대부분을 가로지르는 매우 긴 케이블 고리와 큰 갈고리를 보여 준다.
3. `fast-recover`: 윈치가 팽팽한 케이블과 갈고리를 안쪽으로 빠르게 감아 들인다.
4. `release-propulsion`: 끊겨 열린 갈고리와 케이블 뒤에서 플레이어 코어가 전방으로 추진된다.
5. `electrified-rope`: 팽팽한 로프가 적 접촉점에 닿고 큰 전격이 로프를 따라 흐른다.
6. `collision-explosion`: 로프 몸체가 표적판을 옆으로 때리는 접점에서 폭발과 충격파가 난다.
7. `rope-regeneration`: 연결된 갈고리·로프와 큰 회복 십자가가 동시에 보인다.
8. `double-jump`: 하나의 부츠 아래에 분리된 두 번의 상승 충격이 겹쳐 보인다.
9. `long-range-orb`: 작은 구체와 먼 조준점 사이를 긴 직선 궤적이 연결한다.
10. `overcharged-orb`: 하나의 큰 구체 안으로 에너지가 압축된 고밀도 핵을 보여 준다.
11. `ignition-orb`: 단일 구체의 큰 불꽃 꼬리와 불붙은 단일 표적을 보여 준다.
12. `arcane-slash`: 하나의 넓은 검격 호가 여러 표적을 연속으로 가른다.
13. `meteor`: 불꽃 꼬리를 단 각진 암석이 충돌점으로 떨어진다.
14. `frost-burst`: 중앙 얼음 결정에서 대칭형 냉기 파동이 사방으로 터진다.
15. `shatter-bomb`: 충돌한 중량 폭탄이 큰 파편과 밀쳐내는 화살표로 갈라진다.
16. `thermal-laser`: 기계 방출기에서 이어진 직선 열선이 여러 표적을 관통한다.
17. `electric-orb`: 중앙 구체 주위로 넓은 이동형 전기장이 감싼다.
18. `mobility-surge`: 전진 속도 궤적과 상승 화살표가 하나의 부츠에 함께 붙는다.
19. `low-gravity`: 무거운 금속체가 지면 그림자에서 멀리 떠오른다.
20. `cooldown-reset`: 세 능력 모듈이 하나의 초기화 화살표로 다시 점등된다.
21. `freeze-bolt`: 방향성 얼음 창이 단일 표적을 얼린다.
22. `gathering-orb`: 여러 표적과 입자가 굵은 수렴 화살표를 따라 중앙 구체로 빨려 든다.
23. `chain-dash`: 간격이 분명한 두 개의 전방 대시 잔상이 각각 충격을 남긴다.
24. `thruster-flight`: 조향 날개가 달린 추진체가 긴 연속 배기류로 상승 비행한다.
