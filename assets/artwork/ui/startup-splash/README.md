# ONE ROPE startup splash

- 용도: 앱 실행 직후 필수 리소스를 준비하는 동안 표시하는 전체 화면 스플래시
- 상태: 사용자 승인 export를 runtime에 연결함
- 원본과 export: `export/one-rope-splash.png`, 1672×941 불투명 PNG
- 사용 도구: 사용자가 제공한 완성 PNG를 변형 없이 import
- 출처와 사용권: 프로젝트 사용을 위해 사용자가 이 대화에서 직접 제공
- runtime: `assets/runtime/ui/startup-splash/one-rope-splash.png`와 픽셀 단위로 동일
- 출력: 화면 비율을 유지하는 `contain`; 남는 영역은 검은색이며 제목과 주인공을 자르지 않음
