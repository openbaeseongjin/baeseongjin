# 보스 02 — RESIDENTIAL SECURITY PURSUER

> 상태: **Runtime·Map Editor·polygon mock 구현 / PLAYTEST REV3 반영**

이 문서만 Boss02의 현행 기획 권위다. 이전 초안과 구현 검토 자료는 [`legacy/`](./legacy/)에 보존하며 현재 결정에 사용하지 않는다.

## 1차 개념 — 핵심 경험

플레이어는 골목부터 옥상까지 계속 추격하는 보스의 강공격을 지정 건축물로 유도하고, Rope로 회피한 뒤 열린 약점을 역공한다.

```text
추격 → 공격 예고 → 가장 가까운 생존 Player 표적 선택 → 방향 고정
→ 강공격 → 지정 건축물 충돌 성공/실패 → 성공 시 약점 노출 → 역공 → 추격 재개
```

- 방향 고정 뒤에는 표적을 다시 추적하지 않는다.
- 일반 접촉은 공용 물리 충돌만 일으키고, Player HP 피해는 활성 공격 구간에만 발생한다.
- 지정되지 않은 벽·바닥 충돌과 빗나감은 약점을 열지 않으며, 짧은 회복 뒤 추격을 재개한다.

## 2차 개념 — 전투와 진행

| Phase | 공간과 공격 | 성공 구조물 | 약점 |
| --- | --- | --- | --- |
| P1 | 골목, 방향 고정 직선 돌진 | Wall A / Stairwell Wall B | 후방 추진기, 6초 |
| P2 | 공동중정, 접근 방향 고정 회전 강타 | Central Service Slab | 하부 안정화 장치, 5초 |
| P3 | 옥상, 상승·추적 후 방향 고정 대각선 급강하 | Water Tank / Stairwell Head / Heavy Vent | 중앙 센서, 4초 |

- 골목 → 공동중정 → 옥상은 하나의 `8600 × 3700` Stage에서 연속 진행한다. Phase 면적은 P1 < P2 < P3이며 P3가 가로·세로·면적 모두 가장 크다.
- Phase HP가 0이면 보스가 공격을 멈추고 다음 공간으로 먼저 이동한다. Player는 실제 Rope 조작으로 뒤쫓고, 다음 구역 진입 시 다음 Phase를 시작한다.
- 전환 구간에는 보스 접촉 피해와 강공격이 없다.
- Phase 경계는 Player·Rope·Grapple·표현용 벽이 아닌 Boss 이동·공격 안전 경계다. Boss의 회전 Polygon과 공격 hazard 전체가 현재 Phase 안에 남는다.
- 현재 Phase 밖 Player는 추격과 새 공격 표적에서 제외하며, 경계가 강공격보다 먼저 닿으면 약점 노출 없이 회복한다.
- 각 Phase 기본 HP는 1000이며 Stage 시작 인원으로 `1000 × (1 + 0.5 × (인원-1))`을 한 번 확정한다. 중도 참가자는 현재 시도 HP를 다시 계산하지 않는다.
- 닫힌 몸체에는 기존 속도 비례 일반 피해의 25%가 적용된다.
- 열린 약점에는 기존 속도 비례 일반 피해 100%와 해당 Phase 최대 HP의 25% 고정 피해를 함께 적용한다.
- 한 Phase의 기준 공략은 서로 다른 원인 충돌 4회다. 같은 접촉의 연속 tick은 중복 타격으로 계산하지 않는다.
- 건축물 충돌 성공은 약점만 열며 보스 HP를 직접 감소시키지 않는다.

## 표현과 UI

- 건축물의 표면·충돌·Grapple·발판·필수 이동 경로는 전투 내내 변하지 않는다.
- 파손 표현은 재사용 가능한 먼지·불꽃·충격 파티클을 우선한다. 전용 누적 파손 시스템이나 일회성 오브젝트가 필요하면 생략한다.
- HUD는 현재 Phase HP 하나를 크게 표시하고 전체 진행은 3개 표식으로 표시한다.
- 약점 노출 시 HP Bar와 약점 표식을 같은 색으로 강조하고, 남은 시간은 감소 게이지로 표현한다.

## Map Editor 경계

Editor에서 공간·발판·벽·Anchor·지정 구조물·시작점·Phase 구역·공격 수치와 타이밍·약점 위치와 노출 시간·피해 수치·파티클 배치를 자유롭게 조정한다.

새 공격 상태, 성공 판정 방식, 상태 전이처럼 코드가 필요한 변경은 Editor 범위에 포함하지 않는다.

## 완료 기준

처음 플레이한 사람이 설명 없이 `추격 → 예고 → 방향 고정 → Rope 회피 → 구조물 충돌 성공 → 약점 역공`을 읽을 수 있어야 한다. 모든 공격 표현과 실제 판정이 일치하고, 고정 안전지대 없이 기본 Rope 조작만으로 완주 가능해야 한다.
