## 4. P1 — 생활골목 / 발코니

### 공간
**메인골목**
- 양쪽 3~4층 저층 주거동
- 1층 상점 셔터
- 현관
- 창문
- 자전거
- 화분
- 벤치
- 외부 배관

**샛골목**
- 짧은 소형 골목 2~3개
- Player 회피/방향전환 공간
- Boss의 좁은 전용 추격로는 아님

**발코니**
- 2층/3층
- 하부 프레임/외부계단 주변 명확한 Grapple Target
- Player가 골목 ↔ 발코니를 반복

### 추격 구조
- 초반: Player/Boss 같은 메인골목
- Player가 위쪽/샛길 이동: Boss는 옆 넓은 추격축 유지

### 강공격
**직선 몸통박치기**
- **[현재 게임 기반]** 기존 Pursuit 직선 Dash 문법 기반
- 몸체 낮춤
- 전면 경고등
- 방향 고정 후 돌진

### 충돌 대상
**콘크리트 벽 / 계단실 외벽**

### 파손 표현
**[시각 요소]**
- 콘크리트 균열
- 먼지
- 창문 진동
- 표면 일부 탈락
- 동선 변화 없음

### 약점
**후방 추진기**
