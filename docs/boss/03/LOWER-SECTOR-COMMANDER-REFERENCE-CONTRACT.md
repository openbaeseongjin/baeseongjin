# BOSS03 — LOWER SECTOR COMMANDER 참고 계약

> 상태: **PRODUCT RUNTIME / 3-8 → Boss03 → 4-1**
>
> 이 문서는 Boss03 제품 Runtime의 전투·표현·검수 기준이다. 주 시각 콘셉트 PNG는 참고 자료이며 실제 판정과 Polygon은 authoring spec과 Runtime definition이 소유한다.

## 변경 요약

| AS-IS | TO-BE |
| --- | --- |
| 기믹 이름과 동작 목적이 불분명했다. | 패턴명은 **그랩**이며, 가까운 Player를 처벌하는 확정 연계로 정의한다. |
| 대상·회피·피해·후속 행동이 분리돼 있었다. | 대상 고정, 1.5초 예고, 즉시 거리 이탈 취소, 피해 20+40, 0.5초 해머 연계를 한 규칙으로 연결한다. |
| 시각 경고만으로 탈출 방향을 읽기 어려웠다. | 보스 팔 조준선과 대상 발밑 경고 원을 동시에 표시한다. |
| Rope와 그랩의 관계가 모호했다. | 성공 시 대상 Rope만 즉시 해제한다. |
| 피격 뒤 Player 상태가 불명확했다. | 해머 적중 즉시 조작을 되찾고 보스 앞에 남는다. |
| 그랩 시전과 실제 포획이 서로 다른 공간 거리로 판정됐다. | 보스 중심 기준 800px 하나를 시전·포획·예고 이탈 취소가 함께 사용한다. |
| Arena가 주 바닥과 천장 Crossbeam뿐이라 보스가 높이를 추적하지 못했다. | 주 바닥·단방향 Ledge 3개·연속 Anchor 9개를 사용하고 Commander가 지지면 사이를 점프로 추적한다. |
| 주변 Enemy 소환이 Boss06에만 있었다. | Boss03·06이 같은 소환 계약으로 공격형 Enemy 2마리·15초 cooldown·live 6 skip을 사용한다. |
| 이전 문서에 제작 절차와 내부 구조 설명이 섞여 있었다. | 이 문서는 플레이 규칙, 표현 규칙, 검수 기준만 소유한다. |

## 1. 현재 제품 경계

- 제품 Boss는 Sector 03의 Boss03과 Sector 06 마지막의 Boss06이다.
- Sector 03은 `3-8 → Boss03 → 4-1`을 사용하며 Boss catalog에서 Boss03 항목을 제거하면 기존 direct Gate로 복구된다.
- Boss03은 Polygon Runtime을 현재 제품 표현으로 사용하고 주 시각 콘셉트 PNG는 문서 참고로만 유지한다.

## 2. 전투 핵심

- Commander 본체가 Player 공격의 대상이다. 해머와 경고 효과는 공격 표현이며 별도 공격 대상이 아니다.
- 화면에는 하나의 Boss 체력만 보인다. 체력 단계에 따른 별도 화면 표기나 신규 패턴 추가는 이 문서에서 정하지 않는다.
- 공격은 사슬 훅 **그랩 연계**, 독립 해머 강타, 중량 돌진, 주변 공격형 Enemy 소환이다. 본체는 항상 피해를 받으며 평상시 접촉 피해·넉백·Rope 부착은 없다.
- 1인 체력은 750이고 전투 시작 참가자마다 50%를 추가한다. 중도 합류는 현재 전투 체력을 다시 계산하지 않는다.

## 3. 그랩

### 3.1 의도

그랩은 보스와 가장 가까운 Player가 1.5초 안에 반대 방향으로 탈출하지 못했을 때, 보스 앞에서 해머 내려찍기를 확정으로 맞는 처벌 패턴이다. 은폐나 다른 Player에게 대상이 넘어가는 방식이 아니라, **거리 이탈**이 대응의 기준이다.

### 3.2 대상 선정

| 항목 | 규칙 |
| --- | --- |
| 대상 후보 | 현재 조작 가능하고 생존한 Player만 후보가 된다. |
| 선정 시점 | 예고가 시작되는 순간 보스와 가장 가까운 후보 1명을 고정한다. |
| 대상 고정 | 예고 중 다른 Player가 더 가까워져도 대상은 바뀌지 않는다. |
| 동거리 | 모든 참가자가 같은 Player를 대상으로 보아야 한다. |
| 후보 없음 | 그랩은 시작하지 않는다. |

### 3.3 시간과 결과

| 구간 | 시간 | Player에게 일어나는 일 |
| --- | ---: | --- |
| 예고 | 1.5초 | 고정 대상은 보스 반대 방향으로 그랩 사거리 밖에 나가면 회피한다. |
| 회피 | 예고 종료 시 | 피해·Rope 해제·기절 없이 그랩이 끝난다. |
| 성공 직후 | 즉시 | 대상 Rope가 해제되고, 대상은 보스 앞으로 이동하며 피해 20을 받는다. |
| 구속·연계 | 0.5초 | 0.35초 동안 보스 앞으로 끌려온 뒤 해머가 시작될 때까지 총 0.5초 동안 조작할 수 없다. |
| 해머 | 구속 종료 시 | 해머 내려찍기가 확정 적중해 피해 40을 준다. |
| 회복 | 해머 적중 즉시 | 기절이 끝나고 대상은 보스 앞 위치에서 바로 조작을 되찾는다. |
| 재사용 대기 | 그랩 종료 뒤 15초 | 성공·회피·대상 무효화 모두에 적용된다. |

- 성공한 한 번의 그랩 연계 피해는 총 **60**이다.
- 해머가 적중하기 전에는 기절이 끝나지 않는다.
- 해머 적중 뒤에는 추가 넉백, 강제 이동, 별도 회복 지점 이동을 적용하지 않는다.
- 예고 중 대상이 사망하거나 조작 불가 상태가 되면 그랩은 무효화한다. 다른 Player를 대신 잡지 않는다.
- 예고 중 대상 중심이 보스 중심 기준 800px 밖으로 나가는 tick에 그랩을 즉시 취소한다. 시전 시간이 끝날 때까지 유지하거나 재진입을 기다리지 않는다.
- 지형 뒤에 숨는 것만으로는 회피가 아니다. 보스 중심 기준 사거리 이탈만 회피를 결정한다.

### 3.4 사거리

그랩 사거리는 보스 중심 기준 **800px**이다. 공격 선택, 활성 포획 원, 화면 예고 원과 예고 중 즉시 취소가 이 값을 함께 사용한다. Polygon 외곽 거리와 중심 원을 섞어 시전은 시작됐지만 실제 포획이 불가능한 구간을 만들지 않는다.

### 3.5 주변 Enemy 소환

- 소환은 Boss06과 동일하게 Patrol·Pursuit·Shield·Artillery 순환 pool에서 2마리를 생성한다.
- 성공한 소환 뒤 15초 동안 다시 사용할 수 없고, 살아 있는 해당 Boss 소환몹이 6마리 이상이면 선택하지 않는다.
- 좌·우 소환 위치를 1초 동안 예고한 뒤 서버 중립 Enemy로 등록하며 클라이언트는 일반 Enemy snapshot으로 수렴한다.
- Boss 처치·attempt reset은 해당 Boss가 소유한 소환몹과 그 잔탄을 함께 제거한다.

## 4. Player·Rope·협동 규칙

- 예고 중 Rope를 이용해 사거리 밖으로 나가면 회피로 인정한다.
- Rope 해제는 그랩이 성공한 대상에게만 적용한다. 다른 Player의 Rope와 위치는 바꾸지 않는다.
- 다른 Player는 몸으로 막거나 대신 맞아 그랩 대상을 바꿀 수 없다.
- 대상·예고 시작·회피·피해·Rope 해제·해머 적중은 모든 참가자에게 같은 결과로 보여야 한다.
- 대상이 연결을 잃거나 사망해 무효화되면, 남은 Player 중 새 대상을 고르지 않는다.
- Player별 사망과 부활은 기존 개인 저장 지점 규칙을 따른다. Boss03 참고 기획이 다른 Player의 진행이나 부활 위치를 바꾸지 않는다.

## 5. Arena·회복·종료 경계

- Arena는 `3200×1200`, 2800px 주 바닥, 좌우 낭떠러지, 단방향 Ledge 3개와 연속 `swing-attack` Anchor 9개를 authoring spec으로 소유한다.
- Commander는 Player가 선 지지면이 다르면 일반 공격 선택보다 점프를 우선하며 공용 Boss 지지면 질의와 Physics 점프 컴포넌트로 Ledge와 주 바닥 사이를 이동한다. 서로 떨어진 Ledge는 목표까지 건너뛰지 않고 X축 순서의 인접 Ledge를 한 번씩 경유한다.
- 그랩 도착점, 해머 판정 하단과 지면 파티클 원점은 Commander가 현재 서 있는 주 바닥 또는 Ledge의 같은 `topY`를 사용한다.
- 재도입 승인 전에는 Arena 이미지를 Collision, 이동 경로, Rope 부착 기준으로 사용하지 않는다.
- 재도입을 검토할 때는 그랩 예고 중의 반대 방향 탈출선, 보이는 발판 경계, Rope Anchor, 낙하 후 개인 부활 위치가 서로 모순되지 않는지 점검한다.
- 보스 앞에 남은 Player가 해머 적중 직후 지형 안에 끼이거나, 보이지 않는 벽 때문에 이동하지 못하면 안 된다.
- Sector 03·04 authored 지형은 유지하고 product catalog가 기존 route를 Boss03 Arena로 가로챈다.

## 6. 그래픽 규칙

### 6.1 보스·사슬 훅·해머

- Commander는 일반 Player보다 최소 네 배 이상 큰 실루엣으로 읽혀야 한다.
- 주 시각 콘셉트는 [Commander 이미지 생성 기획](./COMMANDER-IMAGE-GENERATION-PLAN.md)의 둥근 장갑 본체, 두 적·주황 센서등, 사슬 훅과 손에 든 대형 사각 산업 해머를 따른다. 이는 사람 얼굴이나 조종석을 뜻하지 않는다.
- 승인된 한 프레임 본체 외형과 원본·검토 export 상태는 [Boss03 그래픽 원본 README](../../../assets/artwork/characters/boss03-lower-sector-commander/README.md)가 소유한다. 후속 파츠와 상태 이미지는 본체 비율·센서·팔레트·장비 결합 위치를 바꾸지 않는다.
- 대상 쪽 사슬 훅은 그랩의 시각 장치이며 Player Rope·독립 투사체·추가 공격이 아니다. 반대쪽 분절형 손은 별도 손잡이 하단을 쥐고, 손 위쪽의 대형 사각 해머 머리와 함께 해머 내려찍기를 표현한다.
- 손·손잡이·해머 머리는 서로 분리돼야 하며 해머를 팔에 융합하거나 손 자체를 해머로 바꾸지 않는다. 본체, 사슬 훅과 휴대형 해머의 방향은 작은 화면에서도 구분돼야 한다.
- 최소 표현 상태는 대기, 대상 고정 예고, 끌어오기, 해머 내려찍기, 피격, 처치다. 상태 차이는 색 하나가 아니라 자세·외곽선·방향·움직임으로 함께 구분한다.
- 보스 그래픽의 제작 크기, 출력 크기, 좌우 방향과 기준점은 자산 README에 기록한다.
- 그래픽 크기와 프레임 시간은 공격 판정, 피해량, 체력, 물리, 네트워크 결과를 정하지 않는다.

### 6.2 그랩 예고와 피격 표현

- 예고 1.5초 동안 보스 팔의 **조준선**과 고정 대상 발밑의 **경고 원**을 동시에 표시한다.
- 두 표식은 대상을 가리키고, 보스 반대 방향으로 벗어나야 한다는 공간 관계를 읽을 수 있어야 한다.
- 사슬 훅의 전개·비행·전류 표현은 조준선과 경고 원을 대체하지 않으며, 예고 중 Player Rope·Anchor·발판 경계를 오래 가리지 않는다.
- 조준선과 경고 원은 배경·Rope·Anchor·충돌 발판보다 우선해 읽혀야 하지만, 이동 경로와 Anchor를 오래 가리지 않아야 한다.
- 예고, 끌어오기, 해머 적중은 서로 다른 자세 또는 효과로 구분한다. 색만 바꿔 같은 그림을 재사용하지 않는다.
- 피해 20, 기절, 피해 40과 조작 회복은 각 결과가 끝나는 순간 분명히 읽혀야 한다.
- 일반 해머와 그랩 연계 해머가 활성화되는 순간 지면 접점에서 파편이 위로 솟았다가 중력으로 떨어지는 파티클을 한 번 표시한다.
- 데스크톱과 모바일 실제 화면 크기에서 대상, 탈출 방향, 해머 적중 시점을 구분할 수 있어야 한다.

### 6.3 제작물 경계

- 그래픽 원본·투명 PNG·미리보기·도구와 라이선스 정보는 그래픽 자산 가이드의 저작 경로와 README 규칙을 따른다.
- 보스 본체, 사슬 훅, 해머를 쥔 손·팔, 해머 도구, 조준선·경고 원, 끌어오기·해머 VFX는 역할을 나눠 납품한다.
- PNG 외곽선이나 VFX 범위로 충돌 지형, 피격 범위, 피해량, Rope 규칙을 새로 정하지 않는다.
- 검수 전 시안과 레퍼런스 이미지는 게임 배경·지형·Collision으로 사용하지 않는다.

## 7. 오디오 규칙

- 그랩에는 대상 고정 예고, 끌어오기 성공, 해머 적중, 회피 또는 무효화가 구별되는 소리가 필요하다.
- 예고음은 대상이 화면을 보고 회피할 수 있는 시각 경고를 대신하지 않는다.
- 대상의 위험 피드백과 모든 Player가 들어야 하는 해머 적중 피드백을 혼동하지 않는다.
- 위치 기반 단발 효과는 mono로 제작하고, 원본·48 kHz/24-bit master·미리보기·도구·라이선스 정보를 함께 남긴다.
- 음원 파일과 메타데이터는 피해량, 기절 시간, Rope 해제, 대상 선정이나 협동 결과를 정하지 않는다.

## 8. 재도입 전 검수

- 현재 제품 경계가 Boss03·06과 `3-8 → Boss03 → 4-1`을 사용하는지 확인한다.
- 1인과 4인에서 예고 시작 순간의 가장 가까운 조작 가능 생존 Player만 고정되는지 확인한다.
- 예고 중 다른 Player가 더 가까워져도 대상이 바뀌지 않는지 확인한다.
- 1.5초 안에 사거리 밖으로 나간 대상은 피해·Rope 해제·기절 없이 끝나는지 확인한다.
- 성공한 대상만 Rope가 해제되고, 피해 20 → 0.5초 끌기·구속 → 피해 40 → 즉시 조작 회복 순서를 지키는지 확인한다.
- 예고 중 고정 대상이 800px 밖으로 나간 같은 tick에 시전이 취소되고 다른 Player로 대상이 바뀌지 않는지 확인한다.
- Commander가 주 바닥과 세 Ledge의 Player를 점프로 추적하고 snapshot 복원 뒤에도 같은 위치·상태로 이어지는지 확인한다.
- Boss 몸체에 스윙 없이 접촉해도 `스윙 필요`가 표시되지 않으며 일반 Enemy 접촉 안내는 유지되는지 확인한다.
- 일반 해머와 그랩 연계 해머의 지면 접점에서 공격 sequence당 한 번만 위쪽 파편이 발생하는지 확인한다.
- 회피·성공·대상 무효화 뒤 15초 동안 그랩이 다시 시작하지 않는지 확인한다.
- 소환이 좌·우 위치에 2마리를 만들고 15초 전에는 재사용되지 않으며 live 6에서 선택되지 않는지 확인한다.
- Boss03 소환몹이 서버에서만 등록되고 처치·attempt reset 때 잔탄과 함께 제거되는지 확인한다.
- 보스 앞에 남은 대상이 해머 적중 뒤 지형에 끼이지 않고 조작 가능한지 확인한다.
- 실제 데스크톱·모바일 화면에서 조준선, 경고 원, Rope, Anchor, 발판 경계가 동시에 읽히는지 확인한다.
- 그래픽과 오디오 결과가 각각의 자산 가이드·검수 기준을 충족하는지 확인한다.
