# 1. Purpose

`shutdown_state_vfx` represents the final shutdown sequence of the
Continuity Control system.

The purpose is:

> Communicate that the authority system has lost control and the core
> network is powering down.

------------------------------------------------------------------------

# 2. Narrative Function

Theme:

THE SYSTEM CHOOSES WHAT CONTINUES.

Role:

-   final boss defeat feedback
-   system termination signal
-   transition from active control to escape state

Must feel like:

-   controlled shutdown
-   industrial system failure
-   energy depletion

Not:

-   explosion
-   destruction effect
-   magic collapse

-   active system ending
-   authority revoked
-   arena state transition

``` text

SHUTDOWN
```
