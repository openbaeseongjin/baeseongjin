# 1. Purpose

`continuity_core_terminal` is the central control environment asset of
the Continuity Warden arena.

The purpose is:

> Represent the physical authority center where the Continuity Control
> system decides what continues and what is terminated.

------------------------------------------------------------------------

# 2. Narrative Function

Theme:

THE SYSTEM CHOOSES WHAT CONTINUES.

Role:

-   final arena identity object
-   security command interface
-   boss authority symbol

Must feel like:

-   a corporate control mechanism
-   not a normal computer terminal

------------------------------------------------------------------------

# 3. Gameplay Readability

Must communicate:

-   active system control
-   boss connection
-   arena state change

States:

``` text
INACTIVE
    ↓
ACTIVE
    ↓
OVERLOAD
    ↓
SHUTDOWN
```

Runtime controls state changes.

------------------------------------------------------------------------

# 4. Style Lock

Maintain Boss06 visual language:

-   Continuity Control architecture
-   industrial security technology
-   cold steel structure
-   cyan energy control lighting
-   precision mechanical design

------------------------------------------------------------------------

# 5. Required Elements

Recommended:

-   central core housing
-   mechanical locking structure
-   energy conduits
-   control interface
-   maintenance access panels

Avoid:

-   fantasy altar
-   hologram-only object

# 6. Runtime Contract

Purpose:

Arena state controller visual.

Rules:

-   Runtime controls active/inactive state
-   No gameplay logic inside graphic asset
-   No collision modification

Possible states:

## Inactive

-   dim lighting
-   dormant system

## Active

-   cyan energy flow
-   control synchronization

## Overload

-   unstable energy
-   warning feedback

## Shutdown

-   reduced lighting
-   disabled system
