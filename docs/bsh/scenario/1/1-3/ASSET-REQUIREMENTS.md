# 1-3 ASSET REQUIREMENTS — REV8.0

## Main Spine
- Employee Scanner frame
- Warning/Security state panels
- Maintenance Spine modules
- Exit Panel / Security Gate

## Access Annex
- segmented Security gantry
- two authored Access Anchor structures
- large Security Arena floor
- elevated security balcony

## Static Arena Cover

### Cover 1 — Security Console
Low/medium-height equipment console.
Must stand on Arena Floor.
No movement animation.
May use indicator lights only.

### Cover 2 — Equipment / Power Rack
Taller and visually heavier than the Console.
Must stand on Arena Floor.
No movement animation.

Both:
- visually explain solid LOS cover
- non-grapple surface language
- no hazard color unless active enemy telegraph crosses them

## Enemies
- Approach Guard
- Upper Guard
- Access Carrier A

Carrier must have clear Access Module/readability state.

## Lighting
- stable Maintenance white
- clean cyan/white scanner
- localized red/orange Sentry telegraph
- Annex grid light, more regular than 1-1/1-2 failures
- no full red wash

## Audio
- scanner beep
- sentry acquire / track / lock / fire / cooldown
- Cover should visibly/audibly cancel active LOS pressure
- access carrier beacon
- access denied beep
- maintenance override
- violation logged

## Story/UI
System Story remains facility UI.
