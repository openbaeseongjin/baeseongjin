# 1-4 ASSET REQUIREMENTS — REV8.1

## Architecture
- compact Maintenance Calibration Lab
- right Security Vestibule
- thick static Service Baffle
- central Maintenance Node Chamber
- Universal Calibration Frame
- upper-left service exit
- structural room casing

## Service Baffle
Must visually read as:
- fixed diagnostic shielding / equipment partition
- heavy service infrastructure
- non-grapple surface
- no movement rails/pistons suggesting animation

## Maintenance Node
- stable blue-white diagnostic light
- three-card chooser hardware
- local status lamps
- Player-specific consumed/offline presentation per current Runtime

## Universal Calibration Frame

One static rig with dormant instrument modules:
- timed far sensor
- extended-reach anchor receiver
- dual reload sensors
- release speed gate
- neutral Rope contact/impact receiver
- dash/action line gate
- nonlethal pulse emitter
- displacement receiver/puck rail
- remote shot receiver
- vertical scan field

Do NOT physically rebuild the room per card.
Only the relevant instrument changes light/state for that Player.

## Calibration Receiver
Industrial test instrument, not a hostile enemy.
May flash/register events.
No gore/explosion damage fantasy.

## Lighting
Vestibule:
- residual Security amber/red

Node:
- stable blue-white
- calm diagnostic light

Calibration:
- inactive modules dim
- active profile highlights only required instrument
- success changes local lamp to verified state

## Audio
- security tail filtered by Baffle
- Node diagnostic hum
- firmware selection confirmation
- profile load relay
- instrument-specific neutral feedback
- calibration verified chime should sound industrial, not magical
- distant 1-5 live Test Bay machinery at exit
