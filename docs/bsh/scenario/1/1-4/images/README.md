이 문서는 [`../PRODUCTION-ALIGNMENT.md`](../PRODUCTION-ALIGNMENT.md) §1·§2의 상태 표를 기준으로 [Scenario Art 생성 규격](../../../SCENARIO-ART-GENERATION-STANDARD.md) §10 형식에 맞춰 정리했다. `01_scenario_art_reference.png`는 현재 규격 이전에 만들어져 프롬프트·검수 기록이 없으며, 재생성 시에는 규격 §7~§9 절차를 따르고 이 문서에 생성 기록을 추가한다.
