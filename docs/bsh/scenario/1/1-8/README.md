## 1. 한 줄 정의

Maintenance Sector 최상단 Containment Gate를 앞두고
도시 보안 시스템이 플레이어의 상향 이동을 최종적으로 차단한다.

플레이어는 지금까지 익힌:

Rope Chaining
+
Augment
+
Turret Telegraph
+
Wind

를 이용해 두 개의 순차 Security Phase를 돌파하고,

정비기사 권한으로 Containment Gate를 강제 Override한다.

Gate가 열리는 순간
플레이어가 지나온 Lower Maintenance Sector의 전력이
아래부터 순차적으로 꺼지며,

처음으로 다음 구역인 Worker District가 드러난다.

핵심 감정:

"Sector 1 일반 구간을 돌파했다."

+

"아래가 정말 사라지고 있다."

+

"위에는 사람들이 살던 공간이 있다."

## 4. 1-8에서 보스전을 사용하지 않는 이유

Sector 1 일반 구간의 최종 시험은:

"강한 적을 죽일 수 있는가?"

가 아니다.

핵심 질문은:

"이 게임의 Rope 문법을 이해했는가?"

이다.

따라서 Final Challenge는
거대 적보다:

VERTICAL SECURITY ASCENT

형태가 적합하다.

Player는:

싸워서 문을 여는 것이 아니라

움직임으로 Security를 돌파하고

마지막에 Maintenance Override를 실행한다.

이 결정은 Sector 1에 Boss가 없다는 뜻이 아니다. 프로젝트 공통 기획에 따라 Sector 1에도 Boss 1개와 별도의 Boss Battle Timer가 존재한다. 다만 `1-8 CONTAINMENT GATE`는 일반 구간의 최종 종합 Stage로 유지하며, Boss 전투의 위치·전환 순서·시나리오는 이 문서에서 임의로 정하지 않는다. 일반·보스 Timer 전환 규칙은 [`../../../../sector-timer-and-boss-flow.md`](../../../../sector-timer-and-boss-flow.md)를 따른다.

이 Stage에는 새 시스템이나 Boss를 추가하지 않는다. Sector 01 Boss는 별도 전투로 존재하며 위치와 시나리오는 공용 기획에서 확정한다.

Stage는 크게:

1.
Rope Chain 복습

2.
Sentry T1

3.
Mid Safe Deck

4.
Sentry T2 + Pulsed Wind

5.
Containment Gate Override

6.
Worker District Reveal

순서로 진행한다.

T1은 Wind 없는 순수 Security Phase이고,
T2는 같은 Sentry 규칙에 Wind를 겹친 최종 Synthesis Phase다.

두 Turret은 절대로 동시에 Crossfire를 만들지 않는다.

Final Challenge의 이상적인 Flow는:

F
→ Turret TRACK 확인
→ Vent WARNING 확인
→ Swing
→ LOCK 직전 Release
→ ACTIVE Wind 이용
→ G Re-Attach
→ H
→ LOS 탈출

이다.

IMPULSE는 Wind와 Momentum을 합쳐 위험구간을 빠르게 압축하고,

RELAY는 F→G→H를 연속 연결하며,

SHEAR는 Rope Geometry로 T2를 선택적으로 제거할 수 있다.

그러나 모든 Build는
Safe Route로 정상 클리어 가능해야 한다.

H 이후 모든 Gameplay Pressure는 종료된다.

Player는 최종 Gate에서:

ACCESS DENIED

를 받고,

Vertical Maintenance Technician으로서
Service Port를 사용해:

MAINTENANCE OVERRIDE

를 실행한다.

Gate가 열린 뒤:

LOWER GRID SUSPENSION
EXECUTING

이 표시되고,

Player가 지나온 Maintenance Sector의
조명과 설비가 아래부터 순차적으로 꺼진다.

Gate 반대편에는 처음으로:

WORKER DISTRICT — BLOCK 12

가 나타난다.

이곳에는 사람이 직접 등장하기보다:

Apartment
Locker
Canteen
Waiting Chair
Personal Props
Child Drawing
Evacuation Notice

등 생활 흔적을 우선 배치한다.

벽면에는:

EVACUATION GROUP C
WAIT FOR FURTHER INSTRUCTION

를 보여준다.

Player는 이 시점에서:

"사람들이 여기 살았고,
대피를 기다리고 있었다."

까지만 알게 된다.

왜 구조되지 않았는지는
아직 공개하지 않는다.

Worker District Preview 끝에서
Sector 01 일반 구간 Checkpoint를 활성화한다.

이후 Sector 01 Boss 전환과
SECTOR 02 연결 순서는 별도 기획에서 확정한다.

Stage의 최종 성공 기준은:

"Player가 Sector 1에서 배운 모든 Rope 문법을
하나의 자연스러운 이동 흐름으로 사용한 직후,
Gameplay 성취가 Story의 세계 확장으로 바로 이어지는가?"

이다.
