# 1. SECTOR 01 한 문장

> **익숙한 유지관리 인프라가 하나씩 정상성을 잃는 가운데, 주인공은 자신이 아는 시설과 Rope를 붙잡고 임시로 움직이는 법을 되찾는다.**

중요:
- “내 작업장이 망가진다”가 아니다.
- “도시 전체가 붕괴한다”를 처음부터 아는 것도 아니다.
- Player와 주인공은 **설비 하나씩의 이상을 직접 경험하고, 문제의 범위가 예상보다 크다는 사실을 점진적으로 추론**한다.

# 2. SECTOR STORY QUESTION

초기 질문:

> **“무슨 일이 일어난 거지?”**

Gameplay 질문:

> **“정상 이동 설비가 죽었을 때, 유지관리 구조와 Rope로 계속 올라갈 수 있는가?”**

Sector 종료 시 남겨야 할 질문:

> **“이게 정말 한 구역의 고장뿐인가?”**

Sector 01에서 아직 답하면 안 되는 질문:
- 누가 사고를 냈는가?
- 시스템이 의도적으로 노동자를 희생시키는가?
- 도시 권력 구조의 최종 진실은 무엇인가?
- 왜 상층과 하층의 대응이 다른가?

이 질문들은 이후 Sector의 몫이다.

# 3. 주인공 심리 곡선

Sector 01은:

`PANIC → FOCUS → SMALL CONTROL → EXPECTATION BREAK → UNEASE → TEMPORARY COMPETENCE → RENEWED PRESSURE → WIDER UNCERTAINTY`

로 진행한다.

### 시작
- Panic 높음
- Control 낮음
- System Trust는 아직 비교적 높음
- 목표 없음

### 1-4~1-5 중간
- Panic 감소
- Control 상승
- “이 시설을 이용해서 올라갈 수는 있다”는 임시 자신감
- 아직 사고 의미는 모름

### 1-6~1-8 후반
- 환경 계통 이상이 연속되며 다시 불안 증가
- Control은 유지되므로 처음처럼 얼어붙지는 않음
- 사고가 국소적이라는 믿음이 약해짐

### Sector 01 Exit
완료 상태가 아니다.

최종 심리:

> **“상황은 아직 모르겠다. 그래도 움직일 방법은 안다.”**

# 4. ATMOSPHERE MASTER RULE

## 4.1 Core Signature

`FAMILIAR INFRASTRUCTURE LOSING NORMALITY`

정상성을 잃는 순서:

`ACCESS → LIFT → SECURITY ROUTING → DIAGNOSTIC MODE → TEST / CALIBRATION → COOLING → PRESSURE → CONTAINMENT`

처음부터 모든 설비가 죽어 있으면 안 된다.

각 Stage는:
1. 아직 정상인 것
2. 새로 이상해진 것
3. Player가 이용할 수 있는 것

을 동시에 가져야 한다.

---

## 4.2 Light

초기:
- Maintenance white가 기본
- 일부 relay flicker
- Amber emergency가 국소적으로 침투
- Full-screen red emergency wash 금지

중간:
- 1-4 Diagnostic Node에서 잠시 더 안정된 blue-white
- 1-5 Calibration에서 기능적 light rhythm

후반:
- 1-6 Wind/Fan 계통의 불안정한 움직이는 그림자
- 1-7 Pressure cycle과 light pulse 동기화
- 1-8 Containment state change로 빛 자체가 “공간 상태 변화”를 전달

---

## 4.3 Audio

초기 기준점:
- 익숙한 facility hum
- distant motor
- ventilation
- relay tick

이상은 하나씩 추가:
- metal settle
- dead motor silence
- clean security beep
- calibration pulse
- fan surge
- pressure valve cycle
- containment lock impact

핵심:
> **정상음이 사라지는 것 자체가 Story다.**

Alarm을 항상 크게 유지하지 않는다.

Gameplay 집중 구간:
`Rope / Landing / Enemy Telegraph > Story ambience`

# 5. DIALOGUE MASTER RULE — SECTOR 01

Sector 01의 주인공은 아직 생각을 완전히 정리하지 못한다.

허용:

- 불완전한 문장
- 확인
- 임시 행동 결정
- 성공 후 작은 숨

금지:
- 세계관 요약
- 시스템 메시지 재낭독
- 정확한 대형 사고 진단
- 음모 추론
- 영웅 선언
- Rope 정답을 미리 말하는 Tutorial Bark

빈도:
- Stage당 0~1 핵심 Bark가 기본
- 입력 집중 구간 무대사
- 정확한 문장은 Stage별 Story Direction 확정 때 작성

Sector 01 말투 변화:

`말이 끊김 → 짧은 확인 → 임시 판단`

Sector 01 끝에서도 완전히 단정적인 리더 말투가 되면 안 된다.

# 6. STAGE MASTER MATRIX

## 1-1 SERVICE SHAFT

### Spatial Signature
`STRAIGHT SERVICE RISER`

### Gameplay
Rope Basics — Attach / Swing / Release / Landing

### Story Function
`FIRST CRACK IN NORMALITY`

### Player Psychology
당황 → Rope 집중 → 작은 통제감 → 사고 규모 확인으로 다시 불안

### Story Reveal
- Ground Service Access가 잠겨 있음
- Lower Transit unavailable
- Rooftop Maintenance Shuttle이 현재 유일하게 보이는 탈출 가능성

### Atmosphere
**“정상이어야 할 첫 설비가 예상과 다르다.”**

- 정상 Maintenance hum에서 시작
- Relay fault / Shutter 상태가 첫 균열
- Rope 구간에서는 Story noise를 줄임
- Terminal에서 다시 저주파와 정적
- Gate open은 승리보다 “다음 방법이 생김”

### Dialogue Role
당황과 임시 목표만 표현.
정확한 사고 진단 금지.

### Exit Emotion
`불안하지만, 다음 행동은 있다.`

### Handoff to 1-2
Player/주인공 모두:
> “위쪽 Lift는 정상일 수도 있다.”

## 1-2 DOUBLE ANCHOR SHAFT

### Spatial Signature
`CROSSING HOIST / COUNTERWEIGHT`

### Gameplay
Airborne Re-Attach / Rope chaining

### Story Function
`EXPECTATION BREAK THROUGH PHYSICAL OBSTACLE`

바로 해결책을 설명하지 않음.

### Exit Emotion
`정상 설비를 기대하지 말고 우회 구조를 읽어야 한다.`

### Handoff to 1-3
“그래도 Security 구역이라면 정상 안내를 받을 수 있지 않을까?”

# 11. SECTOR 01 SUCCESS CONDITION

Sector 01을 끝냈을 때 Player가 자연스럽게 다음을 느끼면 성공:

1. 나는 Maintenance Worker다.

4. 일부 자동 시스템은 오히려 너무 잘 살아 있다.
5. Maintenance 시스템은 내 Rope 사용을 읽고 적응시킬 수 있다.
6. 문제는 한 설비의 고장보다 넓어 보인다.
7. 그래도 나는 움직이는 법을 조금 배웠다.
8. 위쪽에는 사람이 사는 공간이 있다.
