```text
Y 0 ~ -256
```

“한 길만 있는 공간이 아니다”를 보여준다.

P1에서 최소 두 개의 상승 방향이 동시에 보여야 한다.

### ZONE B — FIRST SPLIT

```text
Y -256 ~ -544
```

Safe Perimeter와 Central Flow가 갈라진다.

어느 쪽도 Build Lock이 아니다.

### ZONE C — PATROL CROSSING

```text
Y -544 ~ -800
```

Patrol Drone T1의 이동 경로가
세 Route와 서로 다른 방식으로 겹친다.

- Safe: Exposure 최소
- Flow: Exposure 짧지만 Timing 중요
- Pressure: Exposure 길지만 가장 직접적

### ZONE D — ROUTE RECOMBINATION

```text
Y -800 ~ -1088
```

세 Route가 다시 가까워진다.

중간에 Route Change가 가능해야 한다.

### ZONE E — MERGE / RELIEF

```text
Y -1088 ~ -1280
```

Encounter 종료.

Player가 2-5 Story Stage로 들어가기 전
10초 내외의 Relief 확보.

## 10. Flow Route

### CENTRAL FLOW SPINE

```text
P1
→ G2
→ C1
→ G4
→ G5 airborne re-attach
```

### 특징

- 가장 짧은 이동 거리 후보

- 1-2에서 배운 Airborne Re-Attach 재사용

- IMPULSE 계열은 일부 Landing Skip 가능
- SHEAR 계열도 동일 경로 통과 가능

### Pressure Route

```text
P1
→ G2
→ C1
→ G6
→ P4
→ G8
→ M3
→ G9
→ P7
```

### 특징

- 가장 직접적인 상승선
- Drone Patrol Line과 가장 오래 겹침
- Kill / Bypass 둘 다 가능
- Cover 대기보다 Rope Commitment로 Exposure를 줄이는 편이 빠름
- SHEAR 계열이 공격적 이점을 느낄 수 있지만 필수 아님
- 다른 Build도 Drone Timing을 읽으면 동일하게 통과 가능

Pressure Route의 목적은:

```text
전투 전용 길
```

이 아니라:

```text
더 큰 위험을 감수해
더 직접적으로 올라가는 길
```

이다.

### 중요

Flow Route를:

```text
RELAY 전용 길
```

로 만들지 않는다.

Base Rope / 다른 Build도
중간 Landing을 사용하면 통과 가능해야 한다.

## 11. Build Route

### NO BUILD-LOCKED ROUTE

2-4는 Build Expression Stage지만
Build 전용 Gate를 만들지 않는다.

```text
IMPULSE DOOR
RELAY DOOR
SHEAR DOOR
```

금지.

대신 동일 공간에서
각 Build가 “더 좋은 해법”을 발견하게 한다.

### IMPULSE 계열 Affordance

- P1 → C1 또는 상위 Landing의 큰 Arc
- Safe Balcony 하나 Skip
- Patrol Exposure를 한 번의 Swing으로 압축
- High Release를 이용한 빠른 Merge

### RELAY 계열 Affordance

- G2 → G4 → G5 → G8 연속 연결
- Landing 없이 중앙 Stack 상승
- Drone LOS를 짧게 통과

### SHEAR 계열 Affordance

Drone이 Patrol Crossing에 있을 때:

```text
Anchor
→ Rope Line
→ Drone Position
```

이 자연스럽게 겹칠 수 있는 Geometry를 제공.

하지만:

```text
Drone Kill
```

은 필수가 아니다.

### Specialization Rule

2-3에서 선택한 Specialization의
실제 효과가 아직 확정되지 않았으므로,
2-4 Blockout은 특정 수치 / 이름에 의존하지 않는다.

최종 Specialization Catalog가 확정되면
다음만 다시 검증한다.

```text
Route Access
Route Efficiency
Recovery
Drone Interaction
```

## 19. Implementation Notes

### 19-1. Current Enemy Architecture

**UPDATED — [PRODUCTION-ALIGNMENT.md](./PRODUCTION-ALIGNMENT.md) 기준 최신 상태**

Generic `EnemyObject`는 타겟이 없으면 `EnemyPatrol.js`(`advanceEnemyPatrol`)로 patrol 이동을, 타겟이 있으면 기존 `idle→acquire→track→lock→fire→cooldown` FSM으로 Projectile 공격을 수행한다. Patrol 이동은 더 이상 "Generic Enemy 기본 동작이 아님"이 아니다 — 2-2에서 도입된 것과 같은 합성 기능이 `Sector02AreaCatalog.js`의 `patrolDrone()` 헬퍼를 통해 이미 재사용되고 있다.

2-4는 2-2와 동일한 `patrolDrone()` 헬퍼를 그대로 재사용하며, 별도의 두 번째 Drone 구현을 만들지 않는다는 원칙은 그대로 유지된다.

### 19-2. Dense Visual Geometry

**VERIFIED — current environment contract**

현재 환경 계약은:

```text
backdrop
collision-aligned terrain
non-collision decoration
```

을 분리한다.

Decoration은 Collision을 만들지 않는다.

2-4에서:

```text
Balcony Rail
Laundry Line
Door Frame
Window Frame
Small Pipe
AC Unit
Shelf
Sign
Cable
```

은 기본적으로 Non-Collision로 처리한다.

### 19-3. `surface.grappleable` Decision Gate

2-4는 이 기능을 다시 검토해야 하는 첫 Stage다.

#### 권장 순서

1. Gameplay Collision만으로 Graybox 제작
2. Dense Near Decoration Mock 추가
3. Wrong Attach 측정
4. 실제로 필요한 Solid Surface까지 Rope Candidate가 되어 문제가 생기는지 확인
5. 문제가 없다면 새 시스템 추가하지 않음
6. 문제가 반복되면 `surface.grappleable` 또는 동등한 명시적 Surface Capability 검토

#### 도입 Trigger 제안

다음 중 하나가 반복되면 구현 검토:

```text
Wrong Attach > 평균 1회 / first clear

또는

시각적으로 필요한 Solid Surface를
Non-Collision으로 만들 수 없어
Rope Candidate Clutter가 발생
```

### 19-4. Route Data

Safe / Flow / Pressure를
별도 Scene이나 Teleport Route로 만들지 않는다.

하나의 연속 Geometry 안에서
Player가 자유롭게 Route를 바꿀 수 있어야 한다.

### 19-5. Specialization Dependency

2-3 Specialization 실제 효과가 확정되기 전에는
2-4 Geometry를 특정 Specialization 수치에 맞추지 않는다.

### 19-6. Multiplayer

두 Player가 서로 다른 Route를 선택해도 된다.

필수 검증:

- Route Split 후 둘 다 Exit 도달 가능
- 한 Player가 Drone Aggro를 끌었을 때 다른 Route가 불합리하게 위험해지지 않음
- Drone Target Switching이 Telegraph를 깨뜨리지 않음
- Merge Deck에서 Body Collision이 Choke를 만들지 않음

## 22. FAIL Conditions

### FAIL — Multi-Route

- IMPULSE 전용 길 / RELAY 전용 길 / SHEAR 전용 길로 분리
- 한 Route만 명백히 빠르고 안전함
- Route 변경 불가능
- 세 Route가 서로 보이지 않는 독립 Tunnel
- Safe Route도 고난도 Airborne Chain 필수

### FAIL — Drone

- 2-2보다 새로운 공격을 갑자기 사용
- 무한 Chase
- Rope Cut
- Drone Kill 필수
- Drone을 멈춰 서서 자동공격으로 죽이는 것이 항상 최적

### FAIL — Recovery

- 한 번 실수로 P1까지 추락
- Recovery에서 8초 이상 재등반
- 두 Player가 좁은 Recovery에서 반복 충돌

### FAIL — Visual / Rope

- Dense Balcony Detail 때문에 Wrong Attach 반복
- Laundry / Rail / Pipe가 무분별하게 Collision
- Cyan Environment가 Rope를 묻음
- Route Surface와 Background가 구분되지 않음

### FAIL — Story

- 2-4에서 Evacuation Group C의 운명을 직접 설명
- 주민이 사망했다는 확정 증거 제공
- A/B/C 계급 의미 공개
