## 10. Flow Route

### CENTRAL BIG-ARC FLOW

숙련자는:

```text

→ G2
→ Release
→ G3 Airborne Re-Attach
→ G5
→ G6
→ P5
```

처럼
중앙 Void를 연속적으로 연결할 수 있다.

### Optional Shortcut

Momentum이 충분하면:

```text
G3
→ high release
→ R3 또는 Upper Approach
```

처럼 중앙 Landing 일부를 줄이는 것은 허용한다.

### 중요

Flow Route는:

```text
실패하면 죽는 고난도 줄타기
```

가 아니라:

```text
Rope를 잘 쓰면
공간이 더 짧고 시원하게 느껴지는 경로
```

여야 한다.

## 17. Background

### Production Decision

2-6은 Sector 02 공통 Background를 유지하되,
**Far / Mid Scale 표현이 가장 중요한 Stage**다.

새 Full Background가 반드시 필요한 것은 아니지만,
기존 Sector 02 Background가 Residential Scale을 충분히 보여주지 못한다면
2-6용 Far/Mid Variant 제작 우선순위가 높다.

### FAR

- 거대한 Worker Housing Tower
- 반복되는 Vertical Block
- 수백 개 수준으로 느껴지는 Window Rhythm
- 먼 Bridge
- 약한 Emergency Light

### MID

- Balcony Stack
- Residential Bridge
- Canteen Module
- Utility Core
- Laundry Frame

### NEAR

의도적으로 줄인다.

2-4 / 2-5보다:

```text
Near Detail ↓
Negative Space ↑
Far/Mid Scale ↑
```

보다:

> “여기에 사람이 정말 많이 살았겠다.”

를 먼저 느껴야 한다.

```text

```

### 19-2. Collision Density

2-6은 Background Scale가 큰 Stage다.

Gameplay Collision을 만들지 않는다.

현재 Environment Contract대로:

```text

2-6은 2-4보다 Near Detail이 적기 때문에

G1~G7 주변의 실제 Gameplay Surface만

```

현재 Rope Momentum이 있을 때

### 19-5. Multiplayer

- P2 / R1 / P4 / R3 / P5 동시 착지 가능

- 한 Player가 빠른 Flow Route로 먼저 P5에 도달해도 다른 Player 진행 가능
- Exit 앞 단일 좁은 Choke 금지

### Scale Comprehension

질문:

> “이 주거구역의 규모가 어떻게 느껴졌나요?”

기대:

> 굉장히 많은 사람이 살던 큰 구역.
> 도시의 한두 채 아파트가 아니라 거대한 주거 시스템.

### Movement Enjoyment

질문:

> “적이 없어도 Rope 이동 자체가 재미있었나요?”

2-6의 매우 중요한 Metric.

### P5 Pause

Player가 P5에서:

```text
1–5 sec
```

자연스럽게 주변을 보는지 기록.

강제로 멈추게 하지 않는다.

### Recovery

주요 실패 후:

```text
≤ 5 sec
```

재진입 목표.

### Wrong Attach

목표:

```text
평균 < 1회 / first clear
```

## 21. PASS Criteria

### Gameplay

- Difficulty ★★☆ 체감
- 2-5보다 확실히 낮은 압력
- Enemy 없음
- New Mechanic 없음
- 큰 Rope Arc를 즐길 수 있음
- Safe Route 존재
- Flow Route 존재
- Build Lock 없음
- Safe Route `swingImpulse = 0` 통과 가능
- 실패 후 5초 이내 재진입
- 적이 없어도 Rope Movement가 재미있음

### Story

- 새로운 대피 정보 거의 없음
- Worker District 규모가 확장되어 보임
- “많은 사람이 살았다”가 환경으로 전달
- Group C의 원인은 여전히 모름
- 2-7 / 2-8 Story를 선행하지 않음

### Visual

- Negative Space가 2-4 / 2-5보다 큼
- Near Detail이 줄어듦
- Far / Mid Residential Scale가 강조됨
- Player가 Architecture 대비 작게 느껴짐
- Gameplay Anchor는 여전히 명확함

### Multiplayer

- 두 Player가 다른 Arc를 사용 가능
- Recovery / Rest Deck이 Choke가 아님
- 빠른 Player가 느린 Player Route를 막지 않음

## 22. FAIL Conditions

### FAIL — Gameplay

- Drone 추가
- Turret 추가
- Wind 추가
- 새 Mechanic 추가
- Platform을 너무 많이 넣어 2-4처럼 Dense해짐
- Safe Route도 Airborne Chain 강제
- 한 번 실패로 Stage 하단까지 추락
- IMPULSE만 재미있고 다른 Build는 단순 점프 반복

### FAIL — Story

- 새로운 Evacuation Terminal 추가
- `TRANSFER SUSPENDED`
- `SHELTER CAPACITY FULL`
- Group A / B
- Priority Access
- 시체 / 피 / Help Message
- “버려진 노동자”를 직접 설명

### FAIL — Visual

- Background Window가 Gameplay Platform처럼 보임
- Near Decoration이 Negative Space를 채워버림
- Neon이 과해 Worker District가 Commercial처럼 보임
- 밝은 Window가 너무 많아 “비어 있는 구역”이 약해짐

### FAIL — Rhythm

Player가:

> “2-5랑 똑같이 긴장됐다.”

라고 느끼거나,

반대로:

> “그냥 아무것도 없는 통로였다.”

라고 느끼면 수정 필요.
