## 19. Implementation Notes

### 19-1. Scenario Source-of-Truth

현재 Master Plan 기준:

```text
2-7 SHELTER ACCESS

2 Patrol Drone
순차 / 구역 분리

LOWER:
Drone 1 + Multi-route

MID:
Safe Shelter Deck

UPPER:
Drone 2 + Build Expression
```

이 구조를 그대로 따른다.

### 19-2. Encounter Ownership

2-7 구현에서 가장 중요한 계약.

```text
Drone 1
owns Zone B

Drone 2
owns Zone D
```

P5 Mid Safe Deck에서는:

```text
Drone 1:
new Acquire 금지

Drone 2:
inactive / new Acquire 금지
```

### 19-3. Crossfire Invariant

아래 조건은 FAIL이다.

```text
Player가 한 위치에서
Drone 1 Projectile과
Drone 2 Projectile을
동시에 피해야 함
```

두 Encounter 사이에
물리적 / 시스템적 Safe Gap이 반드시 존재한다.

### 19-4. Current Generic Enemy Risk

현재 Generic Enemy 기본 구조는
사거리 내 가까운 Player를 공격하는 단순 구조다.

따라서 2-7도:

```text
Cover가 있으니 자동으로 안전
```

을 전제로 하지 않는다.

안전성은 우선:

```text
Encounter Bounds
+
Patrol Timing
+
Activation Ownership
```

으로 보장한다.

### 19-5. Drone Reuse

2-7용 별도 Drone AI를 만들지 않는다.

2-2에서 구현된 Patrol Drone T1을
두 번 배치한다.

차이는 Enemy Stats가 아니라
Level Context다.

### 19-6. Story Zone

P5는 Story 읽기용 완전 Safe Zone.

- Projectile 없음
- Enemy Acquire 없음
- Damage Hazard 없음
- Wind 없음

### 19-7. Build Dependency

정확한 Specialization 효과가 변하더라도
Safe Route는 유지되어야 한다.

Stage Geometry가 특정 Upgrade Patch에 종속되면 안 된다.

### 19-8. Multiplayer

필수:

- Drone별 Attack Cycle Target Lock 유지 우선
- Drone 1이 Player A를 추적 중일 때 Player B가 Zone C로 올라가도 Cross-Zone Fire 없음
- P5에 두 Player 동시 체류 가능
- Player별 Story Display 유지
- Drone 2 Activation이 먼저 올라간 Player 때문에 아래 Player에게 부당한 사격을 만들지 않음
- Exit Merge Choke 없음

- `SHELTER CAPACITY FULL` 공개
- `EVACUATION TRANSFER SUSPENDED` 공개
- `REMAIN IN DESIGNATED AREA` 공개

- Group A / B 없음
- Priority Access 없음
- 현재 Shelter 내부 생존자 존재를 암시하지 않음

- 어느 Build도 필수 Key가 아님

- IMPULSE가 Exposure 압축 가능
- Base Rope로도 통과 가능

### Multiplayer

- Encounter Ownership이 Player별 위치에서도 깨지지 않음
- Story Trigger가 각 Player에게 전달
- P5 / Recovery / Exit에 Choke 없음

## 22. FAIL Conditions

### FAIL — Enemy

- Drone 1 + Drone 2 Crossfire
- Drone 2가 더 빠르거나 더 강한 새 변종
- Burst / Dash / Jam / Rope Cut 추가
- Drone Kill 필수
- Mid Safe Deck까지 Projectile이 따라옴

### FAIL — Gameplay

- 2-7이 2-8보다 더 복잡함
- Boss-like Arena Lock
- 새 Puzzle 추가
- 새 Wind 추가
- 특정 Specialization 필수
- 한 번 실수로 P0까지 복귀
- Story 읽는 중 공격

### FAIL — Story

- Group A / B 공개
- `TRANSFER COMPLETE` 비교 공개
- `PRIORITY ACCESS` 공개
- Suspended 이유 설명
- 기업이 Worker를 고의로 버렸다고 확정
- Shelter 내부 생존자 존재를 직접 암시

### FAIL — Visual

- Shelter가 군사 Bunker처럼 보임
- 대피 물품이 과도한 참사 연출로 변함
- Player / Rope / Drone보다 Emergency Sign이 더 강함
- 2-8 Evacuation Platform 전체가 너무 일찍 보임
