## 19. Implementation Notes

### 19-1. Current Runtime Facts

현재 `main` Config 기준:

```text
Rope Max Attach Distance = 440
Swing Impulse = 780
Enemy Attack Range = 520
Enemy Fire Interval = 1.4
Enemy Projectile Speed = 260
Rope Disabled On Hit = 0.6 sec
```

Stage Geometry는 `780`을 필수로 요구하지 않는다.

Safe Route는 `swingImpulse = 0` 검증 대상이다.

### 19-2. Patrol Band Ownership

2-8의 핵심 구현 계약:

```text
Drone 1 owns Zone B
Drone 2 owns Zone D
```

Drone 1은 M2 이후 새 Acquire 금지.

Drone 2는 Zone D 진입 전 새 Acquire 금지.

### 19-3. One Atrium, Not Two Rooms

Activation Band가 나뉜다고 해서
벽과 Gate로 Encounter를 두 개의 Room처럼 분리하지 않는다.

Player는 같은 Atrium 안에서:

```text
아래 Drone
위 Drone
상단 Transfer Control
```

을 공간적으로 연결해서 볼 수 있어야 한다.

### 19-4. Route Switching

Safe / Flow / Build Route는
중간에 바꿀 수 있어야 한다.

예:

```text
Safe Lower
→ M2
→ Flow Upper
```

또는:

```text
Build Lower
→ M2
→ Safe Upper
```

허용.

### 19-5. Story Safety

P9 이후:

```text
Enemy Acquire NONE
Projectile Pressure NONE
Wind NONE
Damage Hazard NONE
```

Final Story 읽는 동안 피격 금지.

### 19-6. Checkpoint

Master Plan 기준 2-8 종료 후 Sector-end Checkpoint 활성.

Checkpoint는 Final Story 확인 뒤 활성되는 방향을 권장한다.

물리 배치도:

```text
P10 Landing
→ Transfer Control
→ Checkpoint
```

순서가 되도록 Checkpoint를 Transfer Control 오른쪽에 둔다.

```text
Gameplay Clear
→ Final Story
→ Checkpoint
```

이 순서가 Story Skip을 막는다.

### 19-7. Foundation / Specialization Persistence

Checkpoint 이후:

```text
FOUNDATION KEEP
SPECIALIZATION KEEP
```

새 Augment 없음.

### 19-8. Post-Sector Transition — IMPORTANT OPEN DEPENDENCY

Sector 02 Master Plan에는 2-8 이후
`COMMERCIAL TRANSFER SERVICE ACCESS`를 통해 Sector 03으로 이어진다고 적혀 있다.

하지만 프로젝트 공통 Boss Flow에서는
Stage 08 일반구간과 Boss 전환을 분리하는 구조가 사용되고 있으며,
1-8도 Boss를 Stage 내부에 넣지 않고 별도 Transition으로 남겨두었다.

따라서 이 2-8 문서에서는:

```text
2-8 Checkpoint 이후
즉시 Sector 03 진입
```

을 LOCK하지 않는다.

2-8은:

```text
Sector 02 authored general progression
+
Story Climax
+
Checkpoint
```

까지 책임진다.

Boss / Sector 03 실제 연결 순서는 공통 Boss Flow 결정에서 확정한다.

### 19-9. Multiplayer

필수 검증:

- 두 Player가 다른 Route 사용 가능
- 한 Player가 Upper Band 진입해도 Lower Player에게 Drone 2 Fire 없음
- Drone Attack Cycle Target Lock 유지 우선
- M2가 Choke가 아님
- P9 / P10 동시 체류 가능
- Final Story를 각 Player가 확인 가능
- Checkpoint 권위 / 활성 동기화
- 한 Player의 Story Trigger가 다른 Player의 Display를 삭제하지 않음
