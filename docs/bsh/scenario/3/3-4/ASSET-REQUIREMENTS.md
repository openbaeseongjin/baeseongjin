# 3-4 ASSET REQUIREMENTS — REV8.0

## Identity
One commercial building section with two readable layers:

### Public Front
- wider balcony / promenade
- public-facing glazing/signage context
- Scanner-controlled maintenance mounts
- visible Patrol exposure

### Service Back
- narrow stock/service passage
- static racks / maintenance anchors
- lower ceiling / tighter depth
- local service access reader
- Support Guard pocket

## Divider
The central public/service skin separation must be visually and physically credible.
It is gameplay-relevant collision and must explain why Players cannot switch routes halfway.

## Merge
Upper commercial service node visually receives both front and back circulation.

## Gameplay Map rule
Hide decorative retail props unless they collide, grapple, block LOS, host Story, enemy, recovery or gate.
