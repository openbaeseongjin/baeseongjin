# 4-3 ASSET REQUIREMENTS — REV1.0

## Functional world
- Block A entry terrace
- long Garden Skybridge
- visible Block C destination mass
- Block B link-control/fault point
- clearly readable OFFLINE state
- service hatch / controlled drop
- lower bridge-underside maintenance gantry
- SERVICE RELAY B-03 interaction hardware
- Shared Utility Riser B-C
- post-reset B-C service connector / re-entry
- Block C private terrace / exit
- one Pursuit Drone

## Story atmosphere
- maintained upper residential materials
- clean lighting / landscape edge above
- denser MEP/service hardware below
- resident route and worker maintenance route visibly different in finish/width
- no catastrophe rubble blocking the reason for the route

## Relay visual requirement
Relay B-03 must read before the mandatory descent as a specific service objective, not as generic decoration.
Use consistent fault-state grammar:
`BLOCK C LINK / OFFLINE` → `SERVICE RELAY B-03 / MANUAL RESET REQUIRED` → `RESET COMPLETE / RESTORED`.

## Do not make
- train/freight infrastructure
- Transit Wake fans as primary mechanic
- Cutter gallery
- Sector05 corporate command room
- Override terminal lookalike that implies Sector progression
