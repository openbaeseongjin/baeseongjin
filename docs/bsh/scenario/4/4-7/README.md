## Stage sentence

**OPEN REFUGE TERRACE LOOP AROUND A SEALED PROTECTED ASCENT CORE + ONE OPTIONAL INNER SECURITY SPUR**

The player exits 4-6 into a large elevated Refuge Terrace, climbs continuously upward while a single Pursuit threat pressures the outer ascent, breaks that pressure at a full-safe Refuge Airlock, then chooses between a longer threat-free Outer Bypass or a shorter Inner Security Spur containing optional `RESIDENT SECURITY OVERRIDE C`. Both routes merge into a full-safe Final Refuge Control deck and hand off to the Protected Ascent Gate.

## Why this route exists

The Refuge Terrace is the maintained exterior evacuation/service circulation wrapped around a pressurized vertical ascent core. Its landings rise with the actual refuge floors and mechanical/security access bands. The player is not sent sideways or downward for arbitrary challenge design: **every major phase gains height**.

## Gameplay

`4-6 → P1 READ → PERSISTENT PURSUIT ASCENT → M0 AIRLOCK / FULL SAFE → OUTER BYPASS or INNER OVERRIDE C SPUR → M1 FULL SAFE → UPPER RETURN → FINAL REFUGE CONTROL → 4-8`

- Pursuit ×1: lower/main ascent only.
- Late Static Security ×1: inner Override C spur only.
- Simultaneous Pursuit + Static Security: **NONE**.
- Cutter / Wind / Scanner / Moving Platform: **NONE**.
- Required Kill: **NONE**.
