# 5-1 ASSET REQUIREMENTS — REV8.0

## Identity

Corporate Continuity Command Complex.

Desired:

```text
clean
monumental
sealed
precise
controlled
expensive
empty
```

Do not read as:

```text
factory
boiler room
warehouse
ruin
pipe maze
```

## Sealed Core

Four large corporate-control masses.

Visual properties:

- broad uninterrupted finish
- no cyan affordance
- minimal joints
- strong large-scale silhouette
- collision mass readable from distance

These are gameplay objects because they block movement and cannot be grappled.

## Service Hardpoints

Must visually dominate as the only attach affordance.

Use:

- cyan/cool-tech ring
- structural maintenance lug
- inspection bracket
- emergency service mount
- obvious depth from sealed finish

Hardpoint clean zone:

```text
32–48px minimum visual breathing room
```

No background decorative element should resemble a valid Hardpoint.

## Decks

Reception / Control Void / Inspection / Final:

clean command-facility service decks.

Recovery decks:

less visually dominant than route-defining decks.

## Lighting

Normal operational light.

No:
- horror red
- villain spotlight
- corruption glitch
- emergency strobe unless later Runtime evidence requires it

The unease comes from:

> lower systems were cut while this place stayed operational.

## Story Displays

Neutral institutional system displays.

Typography hierarchy:

```text
SYSTEM NAME
STATUS
```

No causal diagram between lower isolation and Continuity Control.

## Gameplay Map Rule

`MAP-PREVIEW.html` shows only gameplay-relevant:
- collision
- non-grappleable core
- grapple targets
- safe/recovery decks
- routes
- exit

Do not add decorative furniture/background props to gameplay map.
