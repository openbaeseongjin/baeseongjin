# Game Builders Seoul 개발 일정

이 문서는 2026년 8월 26일 온라인 예선 제출과 8월 31일 오프라인 본선을 기준으로 역할별 병렬 작업과 필수 선행 관계를 정리한 개발 일정이다.

## 일정 전제

- 게임의 장르·핵심 조작·전체 진행 기획은 완료 상태다.
- 전체 구성은 `6개 섹터 × 섹터당 8개 맵 = 48개 맵`이다.
- 실제 월드는 하나이며 48개 맵은 별도 월드가 아니라 완료 조건과 명시적 출구로 연결되는 진행 영역이다.
- 현재 `SECTOR 01`의 `1-1`~`1-8` 시나리오가 모두 작성됐으며 나머지 40개 맵의 시나리오·레벨 디자인은 새로 작성한다.
- 메인 개발자는 섹터별 시나리오를 받은 뒤 오브젝트·상태·완료 조건·출구·표현 cue를 정리하고 이미지·사운드를 mock으로 연결해 플레이 가능한 흐름을 먼저 만든다.
- 그래픽·오디오 담당자는 메인 개발자가 공개한 목록과 mock 배치를 이어받아 정식 리소스를 병행 제작한다. 정식 리소스는 메인 개발의 선행 조건이 아니며 검증된 결과만 선택 통합한다.
- 증강, NPC 대사·대화 시스템, 엔딩과 관련 UI·게임 요소는 실제 게임 규칙을 결정하므로 관련 섹터 개발의 필수 선행 기획이다.
- 각 섹터 일반 구간은 하나의 총 타이머를 공유한다. Gate 통과가 시간을 보충하고 0초부터 하층 붕괴가 상승하며, 탈락자는 최소 관전 뒤 다음 Gate에서 합류한다.
- 기획자 지정 보스 진입 때 일반 타이머·붕괴와 잔여 시간을 끝내고 별도 보스 타이머를 시작한다. 보스 타이머 0초부터 Arena가 붕괴하며 전원 탈락은 보스 시도만 재시작한다.
- 메인 개발자는 타이머·보충·붕괴 속도를 mock으로 먼저 구현하고 팀과 기획자가 공동 플레이로 최종 수치를 조정한다. 보스 위치·전투 시나리오만 보스 구현의 필수 선행 기획이다.
- 8월 22~23일을 마지막 전체 스퍼트, 8월 24일을 기능·콘텐츠 동결일로 둔다.

## 필수 선행 관계

1. 메인 개발자는 이미 문서가 있는 영역부터 순차 구현할 수 있지만, 각 섹터의 8개 맵 시나리오와 최소 오브젝트·완료 조건·출구 요구가 모두 정리되어야 해당 섹터의 전체 연결을 완료 처리할 수 있다.
2. 증강 기획은 첫 Maintenance Node, 증강 획득·선택·손실과 관련 UI 구현보다 먼저 확정한다.
3. NPC 기획은 첫 NPC 섹터, 대화 trigger·진행·종료와 관련 UI 구현보다 먼저 확정한다.
4. 엔딩 기획은 `SECTOR 06`, 최종 Encounter 이후 전이와 엔딩 UI 구현보다 먼저 확정한다.
5. 정식 그래픽·오디오 리소스는 필수 선행 조건이 아니다. mock 빌드를 기준으로 개발과 검증을 계속하고 준비된 결과만 교체한다.
6. 일반 타이머·Gate 보충·상승 붕괴·최소 관전 흐름은 확정됐으므로 메인 개발자가 mock 수치로 구현한다. 정확한 수치는 구현 선행 조건이 아니며 공동 플레이 뒤 조정한다.
7. 섹터별 보스 1개의 위치·전투 시나리오는 해당 보스 구현의 필수 선행이다. 일반·보스 타이머의 전환과 보스 만료 흐름은 확정됐지만 개발자가 보스 위치나 전투 내용을 추정하지 않는다.

## 확정 상태와 남은 조정

| 항목 | 현재 확정 | 추가 확정 필요 | 차단하는 작업 |
| --- | --- | --- | --- |
| 섹터 일반 구간 타이머 | 섹터 전체 공유, Gate 보충, 0초 상승 붕괴, 최소 관전·다음 Gate 합류, 다음 섹터에서 새 타이머 | 최종 시간·보충량·붕괴 속도, 네트워크·재접속, 최종 cue | 최종 밸런스·출시 검증만 차단하며 mock 시스템 구현은 비차단 |
| 섹터 보스 | 섹터당 1개, `1-8`에는 Boss 없음 | 보스 위치, 전투 목표·Phase·보상, 일반 구간 종료 Checkpoint와 전환 순서 | 각 섹터 보스 구현과 최종 완료 |
| 보스 전투 타이머 | 일반 시간 폐기 뒤 별도 시작, 0초 Arena 붕괴, 전원 탈락 시 보스 시도 재시작 | 최종 시간·붕괴 속도, 보스 시나리오, 최종 cue | 보스 전투 구현·다음 섹터 전환 |

일반 타이머 흐름은 D1에서 mock으로 시작할 수 있다. 정확한 수치는 Q1 누적 플레이테스트에서 팀과 기획자가 함께 조정한다. 보스 위치·전투 시나리오는 여전히 보스 구현을 차단하므로 기획 마감이 정해지면 간트차트에 별도 ID와 선행 관계를 추가한다. 상세 흐름은 [`sector-timer-and-boss-flow.md`](./sector-timer-and-boss-flow.md)를 따른다.
