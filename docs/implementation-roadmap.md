# 초기 컨셉 기준 구현 로드맵

## 제품 기준

> 아크샨식 고정 길이 로프 액션 × 아이작의 로그라이크·아티팩트 구조

순간 플레이의 중심은 로프 숙련이다. 자동 공격과 아티팩트는 전투 방식과 성장 폭을 만들지만 이동과 생존을 대신하지 않는다. 한 판은 체크포인트가 있는 하나의 큰 절차 생성 월드를 아래에서 위로 등반하고, 실패해 체크포인트로 복귀하면 해당 런의 아티팩트 일부를 잃는 구조다.

## 현재 구현 상태

### 완료

- PC·모바일 이동, 점프, 로프 부착·접선 스윙·해제
- 모든 암석 표면 부착과 수평 발판의 아래→위 통과
- 시드 기반 48단계 수직 월드와 카메라 추적
- 사거리 기반 자동 공격과 적 1종의 원거리 공격
- 적 투사체의 로프 절단, 본체 피해, 넉백과 무적 시간
- 체력, 다운, 패배, 낙사와 활성 체크포인트 복귀
- 전투 HUD, 피해 숫자, 충격파, 파편과 화면 흔들림
- 공용 명령·시뮬레이션 경계, PWA 설치와 자동 최신 배포 적용
- 하나의 큰 월드 마지막 암석의 정상 목표와 최종 완료 상태
- 8레벨 간격 체크포인트 생성·활성화·시각 표시
- 활성 체크포인트 사망 복귀와 최근 아티팩트 약 1/3 손실
- 첫 체크포인트의 3종 아티팩트 선택과 즉시 전투 효과 적용
- 데스크톱 보유 HUD와 PC·모바일 공통 획득·손실 피드백
- 각 신규 체크포인트의 1회 보상과 중복 아티팩트 곱연산 누적
- 연속 1,000개 시드의 상승·로프 사거리 통과 가능성 자동 검사
- 경계값·기본값·발견된 문제 시드의 고정 회귀 목록
- 초반 난이도 판단용 활성 시간·처치·피해·로프 절단·첫 보상 지표 수집

### 아직 없음

- 고정 실패 시드 회귀 목록과 초반 2분 플레이 지표
- 실제 조작 기반 전체 등반 자동 검증
- 실제 다인 접속, 명령 전송, 상태 동기화와 협동 부활
- 영구 성장, 자동 자원 생산, 도감, 보스와 다중 바이옴

## 구현 순서

### P0. 로그라이크 한 판의 순환 완성

1. [완료] 하나의 큰 월드 정상에 최종 목표와 `completed` 상태를 추가한다. 완료 후 자동으로 다음 스테이지를 시작하지 않는다.
2. [완료] 첫 비시작 체크포인트에서 아티팩트 선택 보상을 한 번 제공한다.
3. [완료] 아티팩트 인벤토리와 런 한정 효과 적용 경계를 만든다.
4. [완료] 사망 시 활성 체크포인트 복귀와 일부 아티팩트 손실 규칙을 적용한다.

완료 기준: 시작 → 등반·전투 → 아티팩트 선택 → 빌드 변화 체감 → 정상 도달 또는 사망 → 새 런을 한 흐름으로 플레이할 수 있다.

첫 아티팩트는 다음 세 역할을 권장하되 효과와 수치는 구현 전 L2 결정으로 확정한다.

- 화력형: 기본 탄환 피해 증가
- 연사형: 자동 공격 간격 감소
- 로프 연계형: 높은 이동 속도에서 발사한 탄환 강화

로프 연계형을 포함해 아티팩트가 로프 숙련을 대체하지 않고 보상하도록 한다.

### P1. 절차 생성과 초반 난이도 검증

1. [완료] 생성된 핵심 경로의 연속 구간이 로프 사거리 안에 있는지 1,000개 시드에서 자동 검사한다.
2. [완료] 고정 시드 회귀 목록을 두고 실패 시드를 이유와 함께 재현한다.
3. [수집 구현 완료] 시작 2분의 적 수, 피해량, 로프 절단 빈도와 첫 보상 도달 시간을 플레이테스트에서 측정한다.
4. 설명 없이 부착·스윙·해제를 이해하는지 플레이테스트한다.

완료 기준: 검사 대상 시드가 모두 통과 가능 계약을 만족하고, 초반 실패가 조작 오해보다 플레이어 선택에서 발생한다.

### P2. 협동 의미 검증

1. 플레이어 배열과 부활 상호작용을 2인 기준으로 시뮬레이션 테스트한다.
2. 로컬 명령 기록·재생으로 두 플레이어의 결정성을 검증한다.
3. 이후 네트워크 전송 계층을 `PlayerCommand`와 스냅샷 경계에 연결한다.

완료 기준: 싱글과 협동이 같은 월드·전투·생명 로직을 사용하며, 다운된 동료를 살리는 행동이 등반 위험과 선택을 만든다.

### P3. 코어 검증 이후 확장

- 영구 성장과 자동 자원 생산
- 적·무기·아티팩트 확장
- 수집 도감, 보스, 바이옴과 완성형 아트

P0~P2에서 로프 손맛과 한 판의 순환이 검증되기 전에는 착수하지 않는다.

## 확정된 P0 세부 정책

1. 체크포인트 복귀 시 2개 이상 보유한 최근 아티팩트부터 약 1/3을 잃고 최소 1개는 유지한다.
2. 시작점을 제외한 각 신규 체크포인트가 보상을 한 번 제공한다.
3. 선택지는 공격력·연사·로프 연계형 3개이며 중복 선택 효과가 누적된다.
4. 로프 연계형은 스윙 임펄스 성공 후 3초 동안 탄환 피해를 강화한다.

다음 수치 변경은 구조 변경이 아니라 플레이테스트 결과에 따른 밸런스 조정으로 취급한다.
