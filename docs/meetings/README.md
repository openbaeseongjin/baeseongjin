# Meeting minutes

Dated files in this directory are generated by the Discord meeting bot after `/meeting end`. They may include text, display names, external links, and attachment filename/type/size metadata captured from the configured meeting, planning, and coding channels. The bot does not copy signed Discord attachment URLs or file contents.

Because this repository and `docs/` GitHub Pages site are public, GitHub publication is blocked by default until the team explicitly enables `ALLOW_PUBLIC_GITHUB_MINUTES=true`. Enable it only after every participant approves public publication and confirms that the minutes-channel audience is no broader than the source-channel audience.

`transcripts/<date>.md` holds the unedited, per-speaker conversation record captured between `/meeting start` and `/meeting end` (every text message and voice transcript line, verbatim, in order) — not just the classified minutes above. It is written in the same commit and is subject to the same `ALLOW_PUBLIC_GITHUB_MINUTES` gate and team-approval expectation.
