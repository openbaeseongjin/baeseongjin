# 맵 에디터 v2 저작 lane 구현 계획

> **에이전트 작업자용:** REQUIRED SUB-SKILL: 이 계획은 `superpowers:executing-plans`로 task별로 실행한다. 각 단계의 checkbox를 갱신한다.

**목표:** 기존 Runtime 통합 파일을 건드리지 않고 `1-1`·`1-7`의 v2 저작 후보, 결정적 JS 생성물, manifest/composer 계약과 의미 동등성 검증을 제공한다.

**아키텍처:** 이 lane은 `AREA-SPEC.v2.json` sidecar 후보를 읽어 generated Area module을 만든다. 기존 `AREA-SPEC.json` v1과 루트 validator는 메인 개발자 integration commit 전까지 유지한다. v2 module은 legacy Area 배열과 generated Area 배열을 manifest 순서로 원자적으로 선택하는 `composeSectorCatalog` API만 노출하며, 현재 Sector facade wiring은 메인 개발자가 수행한다.

**기술 스택:** Node.js ES modules, JSON, 기존 `AreaDefinition` helper, Node `assert/strict` 기반 focused test.

**설계 명세:** [`../specs/2026-08-19-map-editor-v2-foundation-design.md`](../specs/2026-08-19-map-editor-v2-foundation-design.md)

## 전역 제약

- **최우선:** 메인 개발자와의 source 분리를 유지한다. 기존 `Sector01AreaCatalog`, legacy provider, `LegacyAreaSeamlessSectorRuntime`, 루트 `package.json`, shared test runner, scenario-integration 기준 문서는 수정하지 않는다.
- 새 수기 source는 `src/game/world/area-authoring-v2/`, Node command는 `scripts/area-authoring-v2/`, generated JS는 `src/game/world/areas/generated/`에만 둔다.
- generated output은 수기 수정하지 않고 generator의 `--check`를 통과해야 한다.
- `1-1`·`1-7`의 후보 v2 JSON은 main integration 전까지 `AREA-SPEC.v2.json` sidecar로 유지한다. 메인 개발자는 root v1 validator 확장과 facade cutover를 같은 통합 변경에서 수행한다.
- Runtime은 authoring JSON을 직접 읽지 않는다. generated module은 static ES import만 사용한다.
- source 선택은 manifest 하나만 소유한다. Stage는 `legacy` 또는 `generated` 중 하나만 선택하며 overlay를 허용하지 않는다.
- 이 lane의 완료 증거는 focused test와 generator `--check`다. 전체 `npm test`, `npm run check`, `npm run format:check` ledger와 live cutover 증거는 메인 개발자 소유다.

```js
export function createAreaDefinitionFromV2(spec) {
```

```js
export function renderGeneratedAreaModule(spec) {
    const canonical = canonicalizeAreaSpecV2(spec);
    return `// GENERATED FILE - DO NOT EDIT\nimport { createAreaDefinitionFromV2 } from "../../../area-authoring-v2/AreaSpecV2.js";\n` +
        `export const GENERATED_STAGE_ID = ${JSON.stringify(canonical.stage.legacyStageAlias)};\n` +
        `const SPEC = ${stableJson(canonical)};\n` +
        "export const GENERATED_AREA = createAreaDefinitionFromV2(SPEC);\n";
}
```
