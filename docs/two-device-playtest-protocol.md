# 두 기기 협동 플레이테스트 절차

이 문서는 자동 테스트로 대신할 수 없는 로프 조작감과 협동 플레이 체감을 서로 다른 실제 기기 두 대에서 한 세션으로 검증하기 위한 기준이다. 문서를 작성한 것과 실제 플레이테스트를 통과한 것은 구분한다.

## 준비

- 두 기기에서 배포 페이지를 `?metrics=1` 쿼리와 함께 연다.
- 양쪽 화면의 버전이 같고 최신 배포 버전인지 확인한다.
- 한 명이 4자리 채널을 만들고 다른 한 명이 같은 채널에 참가한다.
- 플레이어 A에게는 조작법을 설명하지 않는다. 플레이어 B는 진행 순서와 기록을 담당한다.
- 시작 전에 아래 기록표에 기기, 브라우저, 접속망, 빌드 버전, 채널 번호와 월드 시드를 적는다.

권장 세션 길이는 15~20분이다. 정상까지 도달하지 못해도 실패 지점과 월드 시드를 남기면 유효한 결과다.

## 메인 시나리오

1. **설명 없는 로프 학습**
   - 플레이어 A가 처음 부착, 스윙, 해제를 성공한 시간을 각각 기록한다.
   - 시작 후 1~2분 안에 로프를 타는 재미와 다음 이동 방향을 이해했는지 짧게 묻는다.
2. **등반과 첫 보상**
   - 첫 체크포인트까지 함께 등반하며 처치, 피해, 로프 절단과 첫 보상 도달 시간을 기록한다.
   - 플레이어 A는 보상 선택 화면에서 잠시 선택을 미룬다.
   - 이때 월드 시간, 적, 투사체와 플레이어 B의 조작이 계속 진행되는지 확인한다.
   - 선택 중인 플레이어 A의 이동·점프·로프 입력만 게임에 전달되지 않고, 실제 전투가 반투명 배경으로 식별되는지 확인한다.
3. **피격과 협동 부활**
   - 적 투사체의 로프 절단과 본체 피격을 각각 경험한다.
   - 무엇 때문에 로프가 끊겼고 체력이 줄었는지 별도 설명 없이 인지했는지 기록한다.
   - 한 명이 다운된 뒤 다른 한 명이 부활시켜 협동 행동이 의미 있게 작동하는지 확인한다.
4. **전멸과 런 손실**
   - 두 명이 모두 다운되도록 진행한다.
   - 활성 체크포인트로 복귀하고 각 플레이어가 최근 아티팩트의 약 1/3을 잃는지 확인한다.
   - 예고 없이 초기화된 것으로 오해할 만한 화면이나 상태 변화가 있었는지 기록한다.
5. **재참가**
   - 플레이어 B가 월드에 남은 상태에서 플레이어 A의 연결을 끊는다.
   - 메뉴에 보존된 채널 번호로 플레이어 A가 명시적으로 다시 참가한다.
   - 기존 플레이어 신원 복원이 아니라 새 연결로 현재 월드 스냅샷에 합류하고, 이후 조작과 전투가 정상인지 확인한다.
6. **계속 등반**
   - 남은 시간 동안 다음 체크포인트 또는 정상 방향으로 진행한다.
   - 반복되는 강제 보정, 하드 스냅, 입력 지연 때문에 등반을 지속하기 어려운 구간을 시각과 함께 기록한다.

### 문제 기록

문제마다 `심각도(진행 불가 / 체감 저하 / 경미)`, `발생 기기`, `월드 시드`, `발생 시점`, `재현 순서`, `화면 또는 영상`, `관련 네트워크 지표`를 남긴다. 같은 현상이 반복되면 횟수도 기록한다.

## 판정

다음을 모두 만족하면 해당 세션을 통과로 기록한다.

- 설명 없이 2분 안에 부착·스윙·해제를 이해하고 로프 이동의 재미를 확인했다.
- 보상 선택 중 월드가 멈추지 않으며, 선택 중인 플레이어만 게임 입력이 차단되고 동료는 계속 행동할 수 있다.
- 로프 절단, 본체 피격, 다운, 부활, 전멸 복귀와 아티팩트 손실의 원인을 플레이어가 이해한다.
- 재참가 후 같은 월드에서 정상적으로 협동 진행을 이어간다.
- 반복 보정이나 입력 지연 때문에 핵심 로프 조작을 지속할 수 없는 문제가 없다.

실패 시 밸런스 수치를 즉시 임의 변경하지 않는다. 월드 시드와 재현 증거를 먼저 남기고, 동일 조건 재현 여부를 확인한 뒤 별도 작업으로 조정한다.
